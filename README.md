# Terrain Editor

A program in which you can deform and modify a terrain in any form you want.

## Usage

```bash
./world
```

## Build

```bash
make
```


For all available build rules:
```bash
make help
```

## Error Handling

The program will return '84' if something went wrong

## Features

- Create an isometric terrain
- Modify the terrain using different tools
- Interact with the editor using the keyboard and mouse
- Save the terrain map

## Project Goals

- Implementing isometric terrain rendering
- CSFML coding
- Events managements
